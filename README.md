**WalT** project allows to build **highly configurable platforms for network experiments**.

This repository allows to build official WalT OS images and publish them on the docker hub.

**Check-out the [website](https://walt-project.liglab.fr) for more info.**

## Building images

Clone this repository with its submodule:
```
$ git clone --recurse-submodules <repository-url>
```
(or run `git submodule update --init` in an existing clone.)

Then run `make` to build all images, or for instance
`make build.debian.rpi32` or `make build.featured.rpi32-chirpstack`
to build a single one.

Raspberry Pi images embed boot files (u-boot builds, firmware files)
generated by repository [walt-node-boot](https://github.com/drakkar-lig/walt-node-boot),
which is included as the git submodule `walt-node-boot`.
These files are taken from docker image
`waltplatform/rpi-boot-builder:<walt-node-boot-commit>`: if this image is
not available locally, `build.py` tries to pull it from the docker hub,
and otherwise builds it (this compiles u-boot, so it may take a while).
To use other boot files, update the submodule commit; uncommitted changes
in `walt-node-boot/rpi` are also taken into account (image tag
`<commit>-dirty`).

Some featured images are based on a base image of this repository (e.g.,
`rpi32-rtk-base` is based on `rpi32-debian`). When building such an image
alone, the local version of the base image is used, or, if missing, it is
built first. Run `make` (or build the base image first) to rebuild it.
